# Product Specification — AI Tennis Journal

## Цель продукта

Создать приложение-дневник для теннисиста, которое помогает:

- фиксировать тренировки и матчи;
- отслеживать физическое и ментальное состояние;
- видеть прогресс;
- получать AI-анализ;
- улучшать игру системно.

---

# Основные сущности

## User

Пользователь приложения.

## JournalEntry

Главная запись дневника.

Типы:

- training
- match
- recovery
- thoughts

## AIInsight

AI-анализ записи.

## WeeklyReport

AI-отчёт за неделю.

---

# Экраны приложения

## 1. Home

Показывает:

- последние записи;
- краткую статистику;
- мотивационный AI-комментарий;
- кнопку создания новой записи.

---

## 2. Create Entry

Форма записи.

### Общие поля

- дата;
- тип записи;
- длительность;
- интенсивность;
- самочувствие;
- настроение;
- заметки.

### Для тренировки

- подача;
- форхенд;
- бэкхенд;
- передвижение;
- тактика;
- ментальная концентрация.

### Для матча

- соперник;
- покрытие;
- счёт;
- результат;
- ключевые ошибки;
- лучшие моменты.

---

## 3. Entry Details

Показывает:

- полную запись;
- AI-анализ;
- рекомендации;
- историю изменений.

---

## 4. Statistics

Графики:

- тренировки по неделям;
- уровень энергии;
- настроение;
- победы/поражения;
- частые проблемы.

---

## 5. Weekly Review

AI создаёт:

- summary недели;
- главные улучшения;
- повторяющиеся ошибки;
- тренировочный фокус;
- психологический анализ.

---

# AI Features

## AI Daily Analysis

После каждой записи AI:

- выделяет главные мысли;
- находит повторяющиеся паттерны;
- даёт краткий коучинг;
- формирует следующий фокус.

## AI Weekly Coach

AI анализирует последние 7 дней и создаёт полноценный отчёт.
