# AI Tennis Journal

Приложение-дневник для тенниса: ежедневные записи тренировок, матчей, мыслей, самочувствия и результатов с AI-анализом и рекомендациями.

## Идея

Пользователь каждый день фиксирует:

- тренировки;
- матчи;
- технические ощущения;
- мысли после игры;
- самочувствие;
- настроение;
- результаты;
- выводы тренера или собственные наблюдения.

AI анализирует записи и помогает видеть прогресс, повторяющиеся ошибки, ментальные паттерны и фокус на следующие тренировки.

## MVP

Первая версия приложения должна включать:

1. Авторизацию пользователя.
2. Создание дневной записи.
3. Разделы: тренировка, матч, мысли, восстановление.
4. AI-комментарий после каждой записи.
5. Список записей по датам.
6. Детальную страницу записи.
7. Недельный AI-отчёт.
8. Базовую статистику.

## Рекомендуемый стек

- Frontend: React Native + Expo
- Backend: Supabase
- Database: PostgreSQL
- Auth: Supabase Auth
- AI: OpenAI API
- Charts: Victory Native или React Native Chart Kit

## Главные сценарии

### 1. Ежедневная запись

Пользователь открывает приложение, выбирает тип записи и быстро заполняет форму.

### 2. AI-анализ

После сохранения записи приложение отправляет данные в AI и получает краткий комментарий:

- главный вывод дня;
- что получилось;
- что требует внимания;
- фокус на следующую тренировку;
- вопрос для размышления.

### 3. Недельный отчёт

Раз в неделю AI анализирует все записи за 7 дней и формирует отчёт по прогрессу.
